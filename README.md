## 🚀 Featured Project

### 🤖 Fine-Tuned Career Counselor Bot

An AI-powered career counseling chatbot designed to help students explore suitable career options based on their interests, skills, and career goals.

The project combines a **fine-tuned TinyLlama language model** with **Retrieval-Augmented Generation (RAG)** to provide career-related responses using a custom career dataset.

**Key Technologies:**

`Python` `TinyLlama` `LoRA` `RAG` `FAISS` `Sentence Transformers` `Flask`

### What it does

- 💬 Answers career-related questions
- 🎯 Recommends relevant career options
- 💰 Provides salary information
- 🧠 Identifies required skills
- 📊 Uses a custom career dataset
- 🤖 Generates responses using a fine-tuned language model
